# moth edit
-- mothratomic dev --
text editor build with framework Löve2d 11.5

## current features
- textinput UTF8
- cursor with arrowkey navigation
- insert, backspace, return, and tab
- scrolling x, y
- line numbers with fixe or automatic margin width
- settings in main.lua (color, font, size, spacing,..)
- fullscreen with F1

## in progress
- mouse input
